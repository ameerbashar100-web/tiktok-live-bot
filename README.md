# BonChat-style Messages — 4 groups

- يفتح مباشرة على Messages.
- توجد 4 مجموعات فقط.
- صور المجموعات يمكن اختيارها من الهاتف بالضغط على صورة المجموعة.
- الصور المختارة تحفظ محلياً في متصفح الجهاز.
- لا توجد شاشة Server URL أو تسجيل دخول أو قاعدة بيانات.
- الملف `index.html` مستقل ويعمل مباشرة على GitHub Pages / Cloudflare Pages.
