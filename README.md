# BonChat Messages UI — 4 chats

هذه نسخة واجهة ثابتة للهاتف:
- تفتح مباشرة على Messages.
- تم الإبقاء على 4 مجموعات فقط: USA2 Oak Crypto، Grupo Marycarmen، Oak Crypto's Growth Trajectory، وArthur Brooks.
- لا يوجد Server URL أو تسجيل دخول أو قاعدة بيانات.
- اضغط على صورة أي محادثة لاختيار صورة من هاتفك. الاختيار محلي في المتصفح.
- لصور ثابتة داخل GitHub، ضع صورك باسم `chat1.jpg` و`chat2.jpg` و`chat3.jpg` و`chat4.jpg` داخل مجلد `assets`.
