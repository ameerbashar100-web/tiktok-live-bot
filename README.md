# ACCE — واجهة التسجيل (مستبدلة)

تم استبدال تصميم المشروع بالكامل ورفع صفحة واحدة `index.html` التي تطابق التصميم الذي طلبته.

ملاحظات:
- رمز الدعوة مضبوط على `dk69kv` كما طلبت (ثابت).
- عند الضغط على "تسجيل دخول" تظهر رسالة: "عذراً، ليس لديك حساب مسبقاً.".
- الملف يقوم بمحاكاة عملية إنشاء الحساب فقط (alert) ثم يعرض الصفحة الرئيسية التجريبية.

لمعاينة: افتح `index.html` في المتصفح.

إذا تريد أي تعديل إضافي (أيقونات، استجابة أفضل، تخزين حساب في localStorage أو ربط API)، قل لي وسأطبق التعديل فوراً.
