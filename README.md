# BonChat — GitHub static version (no login / no database)

This is a clean, static web reconstruction prepared from the available BonChat APK/UI reference. It does **not** contain the original server, account system, or database.

## Upload to GitHub from Android
1. Create/open a GitHub repository.
2. Upload `index.html`, `styles.css`, `app.js`, and the `assets` folder.
3. Enable GitHub Pages from the repository settings.

The page works as a local/static UI. Messages are only shown in the current browser session and are not saved to a server.
