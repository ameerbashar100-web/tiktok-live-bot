# ACCE Landing - Recreated

هذه نسخة مبسطة من واجهة تسجيل المستخدم كما طلبت — تم إنشاء صفحة بداية `index.html` تحتوي على:

- تصميم مشابه للصورة التي أرسلتها (RTL، خطوط عربية احترافية عبر Google Fonts).
- حقل رقم الهاتف، كلمة المرور، تأكيد كلمة المرور، كابتشا ونص رمز الدعوة.
- رمز دعوة مُولّد عشوائياً بخمس أحرف إنجليزية عند كل تحميل للصفحة.
- زرين في الأسفل: "تسجيل دخول" و"انشاء الحساب".
- عند الضغط على "تسجيل دخول" تظهر رسالة: "عذراً، ليس لديك حساب مسبقاً." كما طلبت.
- عند الضغط على "انشاء الحساب" يتم فحص بسيط على جهة العميل ثم يُحاكي إنشاء حساب ويعرض الصفحة الرئيسية (قائمة باقات بسيطة).

ملاحظات مهمة
- هذه نسخة واجهة أمامية فقط (Front-end). لا توجد قاعدة بيانات أو تسجيل حقيقي؛ كل شيء محاكاة في المتصفح.
- إن أردت تخزين الحسابات محليًا أو ربط واجهة API/خادم حقيقي، أخبرني لأضيف ذلك (localStorage أو endpoint حقيقي).

كيفية المعاينة محليًا:
1. قم بتنزيل الملفات أو استنساخ الريبو: `git clone https://github.com/ameerbashar100-web/tiktok-live-bot.git`
2. افتح `index.html` في المتصفح.

إذا تريد تغييرات بالتصميم (ألوان، نصوص، عرض الصور الأصلية من لقطات الشاشة)، أقدر أعدّل وأرفعها مباشرة. قدم لي توجيه واحد واضح وسأطبقه فوراً.
